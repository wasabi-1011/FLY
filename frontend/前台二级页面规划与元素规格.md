> 版本：v1.1 ｜ 日期：2026-09-09 ｜ 状态：v1.0 范围已实现（静态数据）；v1.1 增补单品详情页 + 关于/联系固定页（见 §7）

> 性质：本文是 **前端技术文档 §2 的细化补充**——只回答"要哪些页面、每个页面有什么元素、怎么跳、数据长什么样"，不含通用技术栈说明（见前端技术文档）。

## 0. 需求与拍板结论（本次范围）

用户要求的跳转细化，经澄清后的最终方案：

| # | 用户需求 | 拍板结论 | 落地页面 |
|---|---|---|---|
| 1 | 点男装/女装/童装/热门推荐 → 产品描述界面 | 品类页到"系列 + 款式卡（带描述）"层；热门单开深色页 | `/products/men` `women` `kids` `hot` |
| 2 | 点"查看全部" → 总罗列商品界面 | 新增聚合罗列页 | `/products` |
| 3 | 查看门店地图 → 地图放大 | 整页大图 + 城市联动 | `/stores` |
| 4 | 品牌动态/企业新闻补内容、可跳转、图文并茂 | 列表 + 图文详情两层 | `/news/company` `industry` + 详情 |
| 5 | 风格与官网首页一致 | 复用 site.css 设计令牌与卡片体系 | 全部页面 |

**横切决定**
- 数据：**静态示例数据**（`src/data/siteData.js`），字段结构对齐后端公开接口（`/api/products/...`、`/api/news/...`、`/api/stores/...`），后续接 API 只替换数据层。
- 全站统一导航/页脚（复用 `SiteNav`/`SiteFooter`），锚点导航改**路由跳转**。
- 换页滚动复位、`document.title` 随页面设置（SPA 阶段尽力而为，SSR 二期再做完整 SEO）。
- 所有页面**不出现价格/库存/销量**（PRD N5），热门为人工打标非销量排行（N12）。

## 2. 各页面元素规格

### 2.1 `/products` 产品中心（聚合罗列页）

**用途**：承接首页「进入产品中心 →」「当季系列查看更多」；总览全品类。

| 区块 | 元素清单 |
|---|---|
| 1. PageHero | 面包屑(首页›产品) · 标题「产品中心 PRODUCTS」 · 副题「男装·女装·童装 · 当季系列与主推款式」 |
| 2. 品类入口条 | 3 张系列大图卡（女/男/童，`series-*.jpg`），图内标签 WOMEN/MEN/KIDS，点击→对应品类页；深色 hover 浮层"进入系列 →" |
| 3. 全部款式网格 | 标题「主推款式」+ 说明；款式卡 grid（复用 hot-card 视觉，白底）：图 + 「推荐」角标(部分) + 款名 + meta(品类·款号) + **一句款式描述**；点击→`/products/hot`（本期款式无独立详情） |
| 4. 空态/加载 | 静态数据无需加载；预留空态文案"系列筹备中" |

**技术**：静态路由 `/products`；数据 `PRODUCTS.all()` 聚合三类款式；复用 `.coll-grid/.hot-card` 类；`img` 原生懒加载 `loading="lazy"`。

### 2.2 `/products/:category` 品类页（men / women / kids）

**用途**：男/女/童各自独立 URL（SEO 语义 + 技术文档 §2.2① 路由规划）。

| 区块 | 元素清单 |
|---|---|
| 1. PageHero | 面包屑(首页›产品›女装) · 标题「女装 WOMEN」 · 副题 = 品类主张文案；背景 = 对应 `series-*.jpg` |
| 2. 系列区块（可多个，自上而下） | 每个系列：系列头(名称 + 英文/季别 + 一段系列介绍) + 「N 款」徽标 |
| 3. 系列内款式卡 | 复用 2.1 款式卡元素（图/款名/meta/描述）；同一系列 3–4 款一行/多行 |
| 4. 热门补充（可选） | 该品类若有人工打标款，区块底部横向展示「本季主推」2–4 个 |
| 5. 底部引导 | 「查看全系列款式 →」链接到 `/products`（返回聚合页） |

**技术**：`useParams()` 读 category；非法值（如 `/products/xxx`）重定向 `/products`；无价格库存销量字样（N5/N12）。

### 2.3 `/products/hot` 热门推荐页

**用途**：承接首页热门「查看全部」、导航「热门推荐」。

| 区块 | 元素清单 |
|---|---|
| 1. PageHero(深色变体) | 面包屑 · 标题「热门推荐 HOT PICKS」 · 副题「运营人工标记的当季主推 · 非销量排行」 |
| 2. 热门款式网格 | 深色 `hot-band` 背景；8 款（现有 HOT 数据 + 描述字段）；卡：图+推荐角标+款名+meta+描述 |
| 3. 品类快捷 | 底部 3 个浅色按钮：女装 / 男装 / 童装 → 各自品类页 |

**技术**：静态 `/products/hot`（RR6 静态段天然优先于 `/products/:category`，不会被吞）；对应后端 `GET /api/products/hot`。

### 2.4 `/news/company` 与 `/news/industry` 新闻列表页

**用途**：品牌动态全部内容入口，分类独立 URL。

| 区块 | 元素清单 |
|---|---|
| 1. PageHero | 面包屑(首页›新闻›企业新闻) · 标题「企业新闻 / 行业资讯」+ 副题 |
| 2. 分类切换条 | 两个 tab：「企业新闻」「行业资讯」，当前高亮，切换 = 路由跳转 `/news/company|industry` |
| 3. 新闻卡片网格 | 卡片：头图(16:9) + 分类小标 + 标题(两行截断) + meta(日期·城市/来源)；整卡可点 → 详情页 |
| 4. 底部 | 「返回首页」链接 |

**数据**：`NEWS` 数组按 `cat` 过滤；每类 ≥4 条示例。

### 2.5 `/news/:category/:slug` 新闻图文详情页

**用途**：正文内容页，图文并茂；最需被收录的页面之一。

| 区块 | 元素清单 |
|---|---|
| 1. 面包屑 | `首页 › 新闻 › 企业新闻 › 标题`（末两级可回跳列表） |
| 2. 标题区 | 分类小标(色) · 大标题 · meta 行：日期 · 来源/地点 · 编辑 |
| 3. 头图 | 全宽 16:9 图 + 图注 |
| 4. 正文 | 段落排版：首段引语(加大衬线)、正文段落、**文中插图(居中+图注)**、小节小标题、列表(如适用)；行长 ≤ 720px 居中 |
| 5. 结尾 | 来源/版权行 + 「返回列表 ←」 |
| 6. 相关推荐(可选) | 同分类另 2 条标题链接 |

**技术**：正文为**结构化 JSX 内容**（本轮静态数据）；真实后端返回 HTML（已 XSS 清洗）时用安全渲染，不二次拼接（见前端技术文档 §2.2③）；非法 category/slug 显示"内容不存在"+返回列表。

### 2.6 `/stores` 门店地图大图页（城市联动）

**用途**：首页地图放大版——全站门店位置总览。

| 区块 | 元素清单 |
|---|---|
| 1. PageHero | 面包屑(首页›门店) · 标题「门店地图 STORES」 · 副题「全国 8 城 20 店」 |
| 2. 大图地图(主体) | 腾讯地图 GL JS 全宽（高 ≈ 60vh，比首页 430px 明显更大）；中国视图底图；**城市图钉**（复用金色 pin）；点击图钉→城市信息窗(城市名/N 店/门店清单) |
| 3. 城市联动条 | 页面地图区下方一排城市 chips(全部+北京/上海/广州/深圳/成都/杭州/武汉/南京)，当前城市高亮；点 chip→地图 flyTo 该城 + 下方列表过滤 |
| 4. 门店列表 | 选中城市门店卡：门店名+地址+营业时间(占位"10:00–22:00")；可再点卡→地图飞至单店+信息窗 |
| 5. 兜底 | 地图 Key 失效/离线 → 错误层 + 仍展示城市列表(纯文本) 不白屏 |

**技术**：复用首页 `StoreEntry.jsx` 腾讯地图初始化（KEY、鉴权条清理兜底、GCJ-02 坐标）——建议抽公共 hook `useTencentMap` 或同文件导出共享；城市/门店数据 `STORE_CITIES` 与首页一致。

## 4. 静态数据模型（siteData.js）

```js
// 字段刻意对齐后端公开接口（见前端技术文档附录），接 API 时只需替换取数函数
CATEGORIES = [
  { key:'women', label:'女装', en:'WOMEN', slogan:'…', hero:'/pic/series-women.jpg' },
  { key:'men',   label:'男装', en:'MEN',   … }, { key:'kids', label:'童装', … }
]
COLLECTIONS = [   // 首页三大系列封面（沿用）
  { cat:'women', name:'城野机能', en:'…', season:'2026 秋冬', desc:'…', cover:'/pic/series-women.jpg' }, …
]
ITEMS = [         // 款式（8 款沿用 hot-01..08 + 新增描述）
  { code:'CO-SW001', cat:'women', coll:'城野机能', name:'廓形短风衣', desc:'…', img:'/pic/hot-01.jpg', hot:true }, …
]
NEWS = [          // 企业新闻 4 + 行业资讯 4，正文结构化
  { cat:'company', slug:'aw-2026-global-launch', title:'…', date:'2026-09-07', place:'上海',
    editor:'FLY 品牌部', lead:'…', cover:'/pic/news-01.jpg', body:[ {t:'p'|'h'|'img'|'quote', …} ] }, …
]
STORE_CITIES = [ … 与首页 StoreEntry 城市数据一致（GCJ-02） ]
```

- 款式描述**一句话**（≤24 字），是本次"产品描述界面"的核心新增字段。
- 新闻正文含 `p/h/img/quote` 节点 → 详情页按节点渲染，天然图文并茂。

## 5. 视觉与交互规范（一致性约束）

- **风格令牌**：完全复用 `site.css` `:root`（ink/mut/gold/衬线标题/无衬线正文/`--px` 容器）。新样式只追加不覆写。
- **卡片体系**：品类/款式卡复用 `.coll-card .hot-card` 视觉；新闻卡复用 `.news-card`。
- **深色块**：热门页用 `hot-band` 深底（#12100e）与首页热门区一致；品类页/聚合页白底。
- **交互反馈**：所有可点卡片已有 hover（图上浮 scale 1.04–1.05 + 标题变金）；新增链接 hover 用金 `--gold` 与下划线过渡一致。
- **无障碍**：卡片/按钮为 `<Link>`（键盘可达 + 焦点环）；图标按钮带 aria-label；图片有 alt；正文对比度 ≥4.5:1（深底用 #f3eee6 系）。
- **响应式**：沿用 1023/767/479 断点；款式网格 4→2→2；城市 chips 可横滚。
- **换页体验**：路由切换 scrollTo(0,0)；`document.title` 用 `${标题} · FLY`。
