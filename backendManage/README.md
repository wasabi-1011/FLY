# FLY 后台管理系统（backendManage）

FLY 品牌独立的**后台管理系统**（管理端界面），与前台官网（`frontend/web`）、后端服务（`backend`）分离部署。

当前版本是 **高保真可交互原型**（单文件静态 HTML），用于演示界面、交互、角色权限与内容发布流程。**双击打开为纯本地演示；通过 `http://localhost:8000/admin/index.html` 打开则可连接真实后端**。
已打通数据库的模块：**网页管理·首页轮播图**（v1.4）、**内容运营·新闻与资讯**（v1.5，v1.8 合并为单一入口）、**留言管理**（v1.5）、**商品域·款式列表 + 系列管理**（v1.9 接库，**v2.2 层级重构为 品类 → 款式 → 系列**，**v2.3 款号自动生成 + 图片链路/编辑保存修复**，**v2.4 种子数据 5 款式/8 系列 + 启动.bat 一键恢复商品**）、**门店管理**（v2.6 接库，含地图点选与地址解析）；账号 / 角色 / 日志仍为本地演示。

>   - **前台**：新增 `data/storesApi.js`，门店页改读接口（沿用「空 vs 失败」约定：成功但为空 → 空状态；仅失败 → 回退本地并提示）；地图点位按城市聚合、营业时间取后端值；Key 收敛到 `window.__FLY_TMAP_KEY__`。
>   - 顺带：城市分组与仪表盘「在营门店 / 城市分布」统一走 `allStores()`，不再数 DOM 行（空状态占位行会被误计）。

## 技术要点

- 单文件静态页面：内联 CSS + 原生 JS，无框架、无外部依赖（除地图实时加载）。
- **若依 Vue** 风格：暗色侧栏 `#001529` / 亮色内容区 `#f5f7fa` / Element 蓝 `#409EFF` / 4px 圆角。
- 富文本编辑器：原型用浏览器原生 `document.execCommand`（粗斜下划线/列表/清格式）演示，接真实产品时建议换富文本库（Quill / wangeditor 等）。
- 腾讯地图：`index.html` 中 `TENCENT_MAP_KEY=''` 填入你已申请的 Key 即自动切换真实腾讯地图 GL JS（`map.qq.com/api/gljs`），否则走 SVG 模拟地图；二者均 GCJ-02 火星坐标，无需坐标转换。
