# FLY 后台管理系统（backendManage）

FLY 品牌独立的**后台管理系统**（管理端界面），与前台官网（`frontend/web`）、后端服务（`backend`）分离部署。

当前版本是 **高保真可交互原型**（单文件静态 HTML），用于演示界面、交互、角色权限与内容发布流程。**双击打开为纯本地演示；通过 `http://localhost:8000/admin/index.html` 打开则可连接真实后端**。
已打通数据库的模块：**网页管理·首页轮播图**（v1.4）、**内容运营·新闻与资讯**（v1.5，v1.8 合并为单一入口）、**留言管理**（v1.5）；门店 / 款式 / 系列 / 账号 / 角色 / 日志仍为本地演示。

> - **v1.6（数据一致性修复）**：
>   - 修复**删除后列表不刷新**的 bug——后端 `DELETE` 返回 `204 No Content` 但响应头带 `content-type: application/json`，`apiCall` 原先对空响应体做 JSON 解析会抛错，导致「删完重新拉列表」被跳过。现对 204/205 直接返回 `null`，删完**立即从列表消失**，无需刷新浏览器。

>   - **数据库一键重置**：新增 `backend/重置数据库.py` 与初始快照 `backend/初始数据/初始数据库.db`；启动脚本（`启动.bat` / `start.bat`）新增菜单项 **5 恢复初始数据**、**6 查看数据库状态**，测试后可把 `fly.db` 恢复为初始状态。详见《技术实现文档》§9.1 / §9.2。
>   - 前台改为**以数据库为准**：接口成功但为空 → 显示空状态；仅当接口失败才回退本地默认并提示。首页「品牌动态」区块与 `/news` **同源**（不再使用写死数据）。详见《技术实现文档》§5.5。

>   - **网页管理图片统一**：首页轮播图的「图片」列不再直接渲染缩略图，改为 **「查看图片」链接**（点击弹大图），与款式 / 系列保持一致；不再使用的 `imgThumb()` 与 `.img-th` 样式已清理。

## 技术要点

- 单文件静态页面：内联 CSS + 原生 JS，无框架、无外部依赖（除地图实时加载）。
- **若依 Vue** 风格：暗色侧栏 `#001529` / 亮色内容区 `#f5f7fa` / Element 蓝 `#409EFF` / 4px 圆角。
- 富文本编辑器：原型用浏览器原生 `document.execCommand`（粗斜下划线/列表/清格式）演示，接真实产品时建议换富文本库（Quill / wangeditor 等）。
- 腾讯地图：`index.html` 中 `TENCENT_MAP_KEY=''` 填入你已申请的 Key 即自动切换真实腾讯地图 GL JS（`map.qq.com/api/gljs`），否则走 SVG 模拟地图；二者均 GCJ-02 火星坐标，无需坐标转换。

## 说明 / 边界

- 本目录是**独立的后台项目**，与 `frontend`（前台 web + 既有 admin 骨架）、`backend`（API 服务）均独立，互不依赖，可单独版控。
- 数据均为占位示例，未接数据库。**数据库已定稿 SQLite**，设计见 `docs/FLY品牌官网_数据库设计技术文档_SQLite_v1.0.md`，联调时对接 `backend`（FastAPI）接口即可。
