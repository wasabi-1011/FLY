========================================
最简单：双击「启动.bat」
========================================
D:\FLY网站\启动.bat（start.bat 内容相同，任选其一）
  1  Start ALL        全部启动（前台官网 3000 + 后台管理 8000），并自动打开两个页面
  2  Backend only     仅启动后台管理（端口 8000）
  3  Frontend only    仅启动前台官网（端口 3000）
  4  Stop all         停止全部服务（杀掉占用 8000 / 3000 的进程）
  5  Reset database   恢复初始数据（先停服务，再用初始快照覆盖数据库）
  6  DB status        查看数据库状态（当前库 vs 初始快照）
  0  Quit             退出

说明：脚本会新开两个窗口分别跑后端和前台，关掉窗口即停止对应服务；
      启动前会检测端口是否被占用并给出提示；
      菜单为中英双行，中文显示异常时按英文选 1~6 也能操作；
      脚本为 GBK 编码，请勿用记事本/编辑器另存为 UTF-8（会导致乱码报错）。

手动启动（不用脚本时）
========================================
set PYTHONUTF8=1 #设置确保cmd能识别utf-8编码
pip install -r requirements.txt
//如果没有requirements.txt
//pip install fastapi uvicorn
启动服务：
uvicorn app.main:app --reload --port 8000

前端启动
cd /d D:\FLY网站\frontend\web
npm install && npm run dev
或（分开）
npm install   # 首次需要
npm run dev   # 启动开发服务器

前端通常会运行在 http://localhost:5173 或 http://localhost:3000 等端口，具体看项目配置（查看 package.json 中的 scripts 部分）

cd D:\FLY网站\backend
.\.venv\Scripts\activate
uvicorn app.main:app --reload --port 8000

========================================
原理：为什么必须"跑起来"才能访问
========================================
浏览器访问 http://localhost:3000 实际是向本机 3000 端口发请求，
必须有一个进程在这个端口上"监听"，否则就是「无法访问此页面」。

  3000 端口  ← 前台的 vite 开发服务器（npm run dev 启动的 node 进程）
  8000 端口  ← 后端的 uvicorn（FastAPI），同时挂载了两个静态目录：
                /admin   → D:\FLY网站\backendManage   （后台管理页面）
                /uploads → D:\FLY网站\backend\uploads （上传的图片）

所以：只启动后端，就能打开后台管理页面（8000/admin）；
      要打开前台官网，必须另外启动 vite（3000）。
      两个进程都关掉，页面就都打不开了。

查看当前是谁在占用端口：
  netstat -ano | findstr LISTENING | findstr :8000
  netstat -ano | findstr LISTENING | findstr :3000

========================================
数据库重置（测试后恢复初始状态）
========================================
方式一：双击「启动.bat」选 5（推荐，会自动先停后端服务）
方式二：命令行
  cd /d D:\FLY网站\backend
  python 重置数据库.py            # 用初始快照覆盖数据库
  python 重置数据库.py --show      # 只看当前库 / 快照状态
  python 重置数据库.py --seed      # 只重灌 9 条新闻种子
  python 重置数据库.py --snapshot  # 把当前库另存为新的初始快照

初始基准：D:\FLY网站\backend\初始数据\初始数据库.db（请勿删除）
含：3 个账号 / 7 个页面 / 首页 4 帧轮播 / 9 条新闻 / 20 门店 / 16 款式 / 4 系列
注意：重置前必须停止后端服务（否则数据库文件被占用会失败）。
